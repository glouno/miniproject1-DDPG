# Frozen long-study protocol

Prepared before launch, 5 October 2026. Primary endpoint: 500,000 transitions.
The 300,000-step checkpoint is a prespecified secondary endpoint and convergence
check. No best-checkpoint selection, tuning, or early stopping based on rewards.

Four conditions: DDPG/TD3 × critic LayerNorm off/on. Ten new training seeds
10–19, 40 runs / 20 million total transitions. Keep the pilot numerical settings:
128×128 actor/critic networks; actor has no LayerNorm; hidden critic normalization
is Linear → LayerNorm(eps=1e-5, affine) → ReLU; scalar critic outputs unnormalized.
Gamma .99, tau .005, Adam learning rates 3e-4 / betas (.9,.999) / eps 1e-8,
batch 128, replay capacity 100,000, 5,000 initial uniform random actions,
one gradient round per collected transition. DDPG actor/targets update every
round; TD3 every two rounds, independent critics, min target, smoothing noise
.2 clipped to .5. Exploration noise .1 (relative to action scale). Continuous
LunarLander-v3, gravity −10, no wind, training/evaluation performance horizon
1,000. Rewards/observations are not normalized or clipped. CPU float32, one
Torch/BLAS thread per run; eight independent processes.

Every 25,000 steps (and step zero), evaluate the current frozen actor on the
same 20 held-out initial seeds 20000–20019, separate from pilot seeds 10000–10009.
Score undiscounted rewards up to 1,000 steps. Compute Q1 minus discounted return,
Q2/min where available, episode RMSE and positive-error fraction on every tenth
state/action pair from the first 1,000 transitions. Follow each frozen actor to
natural termination or 10,000 steps. Retain all trajectories, report censoring,
and compare observed suffixes at 2,500/5,000/10,000 horizons. For unfinished
trajectories these are finite approximations, not exact infinite returns. No
critic prediction fills a missing tail. All raw rewards, states, actions, Qs,
returns and indices are saved so discounted sums can be checked independently.
Aggregate pairs within episodes, then episodes within training runs.

Common probes: 12 environment seeds 30000–30011, each with a fixed 30-action
uniform random prefix generated by an independent seeded RNG. A fixed extra
uniform action defines the evaluated action at the resulting physical state.
Reconstruct by resetting and replaying the prefix; verify the observation exactly.
Force that common first action, then follow each frozen current actor. This fixes
starting state/action visitation, while continuation policies can still differ.
A serialized bank and its SHA-256 are frozen before launch; all conditions use it.
Measure signed Q1 error and RMSE on these probes at all checkpoints.

Inference unit: independent training seed. Primary comparisons are paired LN
on-minus-off within each algorithm at 500k for performance, on-policy signed
Q1 error and RMSE. Common-probe calibration and normalized learning-curve area
are supporting diagnostics. Show individual seeds and descriptive pointwise
95% percentile-bootstrap intervals (10,000 seed resamples, RNG seed 419).
Repeated checkpoints/episodes/trajectory pairs are not independent replicates.
No multiplicity-adjusted significance claim or causal bias/performance claim.

No hidden-depth, update-ratio, actor-delay search or TD3 target ablation in this
batch. Consider a focused min-versus-mean target ablation only after inspecting
the main study's stability; that requires a separately frozen follow-up protocol.

Safety/durability: frozen source/config/lock/probe hashes and per-run versions;
atomic model, diagnostic and progress files; append-only fsynced metric journal;
latest and previous resumable states at every evaluation checkpoint. Resume
states include online/target networks, optimizers, replay ring, RNGs and episode
prefix/reset RNG. Recover the actual Box2D state by replay and assert it matches;
trim journals to the saved byte offsets and archive newer partial artifacts.
Resume was tested against uninterrupted training and canonical pilot updates.
Load these full pickle-based training states only from this local trusted study.

A macOS launchd job runs caffeinate -i -s for the runner's lifetime, preventing
idle system sleep (and system sleep on AC). The display can sleep. This does not
make closed-lid operation reliable. A five-hour execution deadline pauses active
runs gracefully and leaves remaining jobs pending; it is not reward-based stopping.
The runner automatically analyses all runs if complete; failures/deadline status
are recorded and can be resumed with the frozen runner. Raw data remains ignored
by Git and must be backed up separately. The shared report remains on Samskrift.
